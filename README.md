# Using AI Coding Agents Effectively (scope description, title pending)

[简体中文](README.zh-CN.md) · [Chinese outline](book/zh-CN/README.md)

A book in preparation for people with or without programming experience who want to use AI coding agents to build, check, and maintain useful software.

Readers will use existing coding agents to understand codebases, implement features, fix bugs, check changes, and deliver working software. The book explains how to define tasks, provide context, guide execution, recover from problems, and build reusable working habits. It does not teach readers to build an agent system.

Effectiveness includes correctness, maintainability, human effort, waiting, rework, and model usage. Generation speed and token counts alone do not establish improvement.

## Current state

On October 17, 2026, the user clarified the scope as using AI coding agents. The earlier interpretation about developing a first agent application has been corrected. Programming experience is not a prerequisite. The original fixed office-work cases remain as historical material.

The audience and purpose are established. The provisional outline has five parts and twenty chapters. The formal title, teaching project, and coding tools are undecided. The [Chinese sample chapter](book/zh-CN/13-working-with-a-stuck-assistant.md) is included and tracked as revising. Its teaching scenario has not been tested. No chapter is final, and no runnable exercise or reader trial is complete. The repository retains its original name for now.

Wombat may inform research into coding-agent use, but is not the teaching project or a required tool.

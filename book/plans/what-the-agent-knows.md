# 样章材料卡：它现在知道什么，又会忘掉什么

任务 ID：`what-the-agent-knows`。对应第二部分第 6 章。正文见 [样章](../zh-CN/06-what-the-agent-knows.md)，状态见 [工作状态](../workflow.json)。

## 读者、问题与论点

面向有无编程经验、已有初版工具的读者。教学情境为精简文件清单界面时隐藏了路径，导致两份同名文件难以区分。此前约定保留可区分来源的路径信息，但不能仅凭输出推断助手忘记了该要求。

本章判断：区分项目中存有信息、信息进入当前上下文、助手据此行动；通过读取记录、当前约定和可见结果发现缺口，补充与本次任务有关的材料，清理仍从文档、引用和记忆进入任务的过期要求。结果应是读者知道要补什么、如何判断补充是否有效，不要求读取模型内部思考。

登记为 argument。同名文件情境为教学设计，未提供代码或样本；仓库清理段落为实际维护记录。两者均不构成已验证的跟做练习，也不确立全书主项目。

## 材料与证据

- Anthropic 上下文工程：当前上下文、按需读取、压缩和持久记录；用于机制解释，不引用效果数字。
- Lost in the Middle：核读 2023 年论文摘要，多文档问答与键值检索中相关信息位置影响表现；不推断当前产品的具体故障或建议机械移动提示词。
- Claude Code 记忆文档：规则与记忆作为上下文，不是强制配置；载入方式按产品和版本核对，不泛化为所有工具相同。
- 旧文档经读取、规则加载或记忆再次进入上下文，可持续干扰任务；机制参考官方加载说明，Git 保留历史、删除过期文档、单一现行依据和重读步骤属于编辑建议，不保证完全阻断。
- Git 官方 commit 与 restore 文档：提交保存选定内容，可以从保留的历史版本恢复文件；不把未提交内容当作已保留，也不把删除文件视为清除所有上下文。
- 同名 PDF、隐藏路径、旧显示方案与当前约定的冲突均为教学设计。未测量整理材料是否提高成功率。
- 本书仓库清理：[操作记录](../reviews/repository-cleanup-2026-10-18.md) 支撑旧要求也可能写进检查脚本的实际发现；不推断后续误读率，也不替代同名文件情境的试做。

## 验收与待补

- 不把界面出错直接归因于遗忘；读过、复述过与按要求完成分别核对。
- 区分普通资料、当前项目约定和已放弃的草案，保留真实来源；不把样本里的指令当作用户授权。
- 删除前确认待保留内容已提交，优先由 Git 保留历史；仅确有随项目提供需要的旧资料继续保留。
- 不以日期新旧判定要求效力，不把归档目录或新会话当作自动隔离；核对可访问范围内的旧引用、加载入口与记忆。

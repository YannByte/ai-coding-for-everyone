# 第 1 章样章材料卡

任务 ID：`start-with-your-problem`。正文见 [样章](../zh-CN/01-start-with-your-problem.md)，状态见 [工作状态](../workflow.json)。

## 读者、问题与论点

无编程经验的读者记得培训通知中的报名要求，却找不到对应文件。开始只需电脑和可对话的编程助手，从自然语言求助进入。助手在授权范围内自行选择搜索工具、批量读取资料、执行并处理反馈；读者提供目标、必要访问条件和只有自己知道的信息，核对最终结果。命令行与环境问题也由助手先检查，必要的人类操作再说明。

本章判断：不必独自准备完整技术方案才开口；持续补充真实信息，并以文件原文判断是否找对。章节结果是理解怎样开始并继续对话，最后由反复找文件的需要引出可重复使用的工具。

正文沿同一次求助连续叙述：说出问题和大致范围、确认访问条件、助手自主搜索与批量处理、比较不同年份的候选资料、询问年份、读取并核对报名要求。不安排读者逐份挑文件、设计搜索步骤、转交每条报错；需要用户介入时说明具体缺口。命令和环境问题只作短说明，不展开配置教程。

登记为 argument。人物采用第二人称教学设定，文件、对话和查找结果均未实测，不构成可直接复现的操作练习，也不确定全书主项目。没有实际作者或读者成功记录。

## 材料与证据

- Tw93 的非技术人实践文章用于参考从手头工作进入、亲手核对结果的组织方式，来源见 [参考来源](../../docs/sources.md)。不采用专业开发者的技术需求清单、固定完成时间或必定正确的表述。
- Claude Code 官方 How Claude Code works 的 The agentic loop、Tools 说明工具调用与结果反馈。已于 2026 年 10 月 18 日核读；只支持对应产品能力说明，不证明教学情境成功。
- 培训通知、自主搜索与批量读取、不同年份候选文件、访问条件及环境问题均为教学设计，不是执行实录。终端和运行环境仅作当前操作所需的通俗解释，不提供未核实的按钮、命令或安装流程。

## 验收与待补

- 从具体困扰起笔，不先列学习清单；询问、查看材料、处理卡点和核对原文都应有具体对象。
- 保留现成工具能解决问题的路径，不预设一定需要编程。
- 选定工具与版本，制作无私人信息的公开资料，验证读取范围、同义线索和原文定位；记录失败及所需人工操作。
- 邀请无编程经验读者试读，检查自然对话是否易于开始、术语解释是否够用；实际练习须另做作者和读者试做。

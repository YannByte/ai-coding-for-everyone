# Manuscript instructions

Follow [root instructions](../AGENTS.md). The [Chinese outline](zh-CN/README.md) owns the book's sequence.

Follow [Chinese writing rules](../docs/chinese-writing.md), [writing method](../docs/writing-method.md), and [review rules](../docs/review.md) for arguments, cases, instructions, exercises, and review. Use the [terminology table](../docs/terminology.md).

- Before drafting, identify the work problem, the reader's decision, the intended result, prior knowledge, and evidence gaps. Follow the review criteria in the writing method before marking a chapter reviewed.
- Each chapter develops an argument through a concrete work problem, a choice, an observable result, and an explanation. Avoid turning the book into a sequence of software screens or prompt templates.
- Assume everyday computer experience. Explain technical terms at the point of need. Keep consequential operations and judgment in the prose; place volatile installation details beside the runnable example when it exists.
- Write clear, connected Chinese prose. Use familiar words, precise verbs, and restrained emphasis. Keep each prose paragraph on one source line; preserve code, tables, and quotations. Do not impose a fixed article-length limit on chapters.
- Use the recurring report as the main case, screenshots as the starter, and expense documents for transfer. Personal rules and changing inputs provide depth; more features are not automatically progress.
- Label teaching scenarios and reconstructed dialogue. Source real quotations and claims. Report timing and reader outcomes only with evidence; author testing is not novice testing.
- Compare existing software fairly. A configured existing tool can be the right result. Explain preparation, checking, remaining manual work, and maintenance when discussing benefits.
- Keep stable chapter filenames once published; update incoming links when moving them. Do not create empty translated chapters to suggest coverage. For translations, also read [translation instructions](../translations/AGENTS.md).
- Review the argument and sources as well as links and formatting. A sample chapter should expose where a reader gets stuck, not only show an ideal successful conversation.

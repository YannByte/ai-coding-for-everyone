# 固定汇报文件更新

状态：案例设计，尚未完成试做。

每月拿到新的 Excel 数据，需要更新同一份 PPT。版式和用途大体不变，数字、日期、分类与图表需要同步变化。

## 预期材料

- 连续三期自制工作数据，日期、条目与汇总能够相互对应。
- 一份固定 PPT 模板，包含概览、分类结果、趋势与需要人工补充的说明。
- 工作要求、对照结果，以及一批未用于本轮调试的练习数据。

## 递进安排

先正确更新一页，再完成整份汇报。下一期增加月份或分类，检查文字与图表是否同步。随后引入文件改名或必需列缺失等变化，练习识别问题并恢复使用。

人工说明与计划应保留，工具不能根据几个数字自行编造业务原因。第一批材料保持清楚可用，异常按教学需要逐次加入。

## 怎样判断是否完成

数字能追溯到源数据；日期、单位和图表一致；模板没有意外改变；原件被保留；得到的文件可以用于汇报，且无需逐页重新排版。

尚未承诺完成耗时或普通读者成功率。实现方式待试做确定。

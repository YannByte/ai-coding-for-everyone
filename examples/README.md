# 案例与练习材料

当前只发布案例设计，尚无可运行工具或完整练习包。

| 案例 | 角色 | 设计说明 |
| --- | --- | --- |
| 固定汇报更新 | 主线 | [recurring-report](recurring-report/README.md) |

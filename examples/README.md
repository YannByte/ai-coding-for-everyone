# 案例与练习材料

当前用于练习使用 AI 编程助手的软件项目与开发任务尚未选定，没有可运行工具或完整练习包。案例应支持理解代码、实现需求、修复缺陷和审查交付，具体任务和验收条件在选定后写入对应说明。

## 选材要求

- 使用有明确用途、可独立检查结果的普通软件项目，任务规模适合目标读者练习，并解释零基础读者需要的概念；不以开发 Agent 为目标。
- 能引出需求表达、上下文选择、代码修改、测试与审查的必要判断，允许读者迁移到自己的项目。
- 正常运行与故障实验都能在可控环境中完成，材料可以公开。
- 保留失败版本、观察依据、修复过程及独立验证，区分设计与实际试做。
- 记录所用工具、模型版本、人工介入、等待、返工及可获得的用量数据；用目标读者试做检验效果，不编造不可测的收益。

原创代码采用 MIT，原创说明与教学素材采用 CC BY-SA 4.0，第三方材料单独核对许可。不要提交私人日志、凭据或未经授权的工作资料。

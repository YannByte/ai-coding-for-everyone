# 整理报销票据

状态：案例设计，尚未完成试做。

PDF 与图片材料散落在文件夹中，需要按本人要求排列、合并，并生成能对应源文件的清单。

## 预期材料

带明显「教学样例」标记的自制材料，覆盖不同尺寸、较长文件名、同文件重复导入等条件。示例不包含真实个人信息或可冒用的票据身份。

## 递进安排

先完成排序、预览和合并，再考虑字段提取。无法识别的日期、金额应留空或提示确认，不猜测。调整页边距时，预览与最终输出要保持一致。

## 怎样判断是否完成

没有漏页，顺序符合要求，缩放后能读清，清单可以对应源文件，原件被保留。打印场景需实际试印后评价。

是否需要打印取决于具体流程。本案例展示文件整理与规则迁移，不承诺输出符合所有单位或地区的报销要求。

# 审稿：按读者可能卡住的位置检查

先审事实和逻辑，再审表达，最后处理排版。对实质问题记录原文位置、读者可能误解什么、建议怎样修改，以及是否需要补充试做。

| 检查项 | 通过的依据 |
| --- | --- |
| 章节作用 | 能说出本章帮助读者作出的判断，并找到支持它的论述 |
| 事实与条件 | 来源、教学设定和实测结果可区分；条件、例外和不确定性没有被删掉 |
| 术语与指代 | 同一对象名称稳定；执行者、对象和否定范围明确 |
| 解释与衔接 | 必要概念先解释；段落之间有可理解的因果或转折 |
| 操作与反馈 | 读者知道何时开始、做什么、怎样核对、何时停止 |
| 失败与迁移 | 能从结果差异继续检查；练习允许替换材料或规则 |
| 实际收益 | 说明解决了什么、仍要做什么；没有把预期收益写成实测收益 |
| 翻译准备 | 原文不依赖未解释的缩写和隐含指代；关键术语可对应 |

样章试读时，请符合定位的读者用自己的话复述判断依据。需要动手的章节，再请读者独立试做，记录停顿、误解和结果差异。作者的解释或现场帮助也要记下，避免把有人辅导的完成记成独立完成。

检查器只辅助发现格式和部分用词问题。它不能判断读者是否理解，也不能证明案例有效。没有试读或试做时，明确记录尚未验证。

## 交付审稿结果

对每个实质问题给出文件位置、原文、对读者的影响和修改建议。先报告会造成错误判断或操作的问题，再报告理解障碍，最后报告表达问题。无需凑齐问题数量。

仅审阅时不修改正文；用户要求修改时直接处理授权范围。改写后再次核对事实、条件、否定范围和确定程度，并检查上下文衔接。试读、试做和实际结果缺失时，如实报告，不用自动检查通过替代。

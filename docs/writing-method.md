# 本书的写作方法

本书把 ASD-STE100 的可迁移原则用于论述、案例、操作、练习和翻译：术语稳定，条件明确，让读者看得懂判断依据，也知道怎样核对结果。段落仍保留解释、推理和自然叙述。

方法已经内化到仓库的 [book-writing 技能](../.agents/skills/book-writing/SKILL.md)。撰写、改写和审稿时，仓库规则会引导协作者读取这个技能；也可以显式使用 `$book-writing`。所有必要文件都随仓库提供，无需依赖作者本机的技能。

- [写作方法与改写示例](../.agents/skills/book-writing/references/writing-guide.md)：章节准备、论述、操作、提示词、结果和练习。
- [审稿标准](../.agents/skills/book-writing/references/review-guide.md)：读者判断、事实条件、术语、操作反馈与迁移。
- [术语表](terminology.md)：中文首选词、英文对应词与含义边界。
- [中文写作约定](chinese-writing.md)：与通用中文写作技能配合的方法。

ASD-STE100 是英文技术文档标准。本书参考其方法，并按中文和书籍的需要调整；这不表示书稿通过标准符合性检查。参考来源和具体取舍见技能中的写作方法。

# 本书的中文写作约定

本项目使用随仓库提供的 [中文写作技能](../.agents/skills/tech-doc-style-chinese/SKILL.md)。本文件是该技能的项目覆盖说明。[本书写作技能](../.agents/skills/book-writing/SKILL.md) 将 ASD-STE100 的可迁移原则用于全书写作与审稿；书稿结构仍以 [书稿规则](../book/AGENTS.md) 为准。

## 按内容应用

- 正文与案例叙述：采用写作方法中的问题界定、概念解释、判断依据与结果核对，保持段落之间的推理与叙述。允许称呼读者为「你」，不强制改成无主句或角色名称。
- 安装、操作和排错说明：进一步采用技能中的受控技术写作方法，说明条件、动作、可观察结果与恢复方式。
- 提示词、代码、命令、报错原文与直接引用：保留需要复现的内容，不为统一文风改动字面量。
- 标题与目录：说明具体主题，不套用口号或强制整齐的标题句式。

## 教学设定与事实

允许设计教学人物、数据和经过整理的对话，并说明其性质。技能的事实保真要求用于防止将这些设定写成真实亲历、原始引语或已验证效果。真实来源、试做结果及读者反馈保留原有条件和确定程度。

## 用语与排版

正文采用常用词、明确动词和连贯段落。技术名词首次出现时解释用途。中文与英文、数字之间的留白、引号与术语大小写沿用技能约定；固定引用和官方名称保留原样。

关键概念使用 [术语表](terminology.md) 中的首选表达。需要讨论 Agent、skill 或库时，在实际用途出现处解释，不预先堆放术语。技能不替本书设定章数、篇幅或叙事模板。

## 检查与修改

统一仓库检查会执行技能自身测试，以及本项目中文内容的轻量检查。确定错字等错误会阻止检查通过；语气、称呼和语境提示交由作者判断，不采用 `--strict` 将它们全部变成错误。

只检查一个文件时可运行：

```sh
python3 .agents/skills/tech-doc-style-chinese/scripts/lint_copy_rules.py README.zh-CN.md
```

段落合并工具可能修改文件。先用 `--check` 查看，不默认对全仓库执行自动改写：

```sh
python3 .agents/skills/tech-doc-style-chinese/scripts/unwrap_md_paragraphs.py --check book/zh-CN
```

检查器不能证明论点成立或文章好读。审阅仍需检查事实、判断过程、段落衔接和读者是否能够理解。

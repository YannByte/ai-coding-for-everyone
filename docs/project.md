# 项目范围与进度

## 已确认的决定

以下决定来自已确认的项目讨论，后续任务以此为起点。不要因为切换对话或写作工具重新立项。调整已确认决定时，说明新依据、影响范围和替代关系，不将建议自动写成确认结果。

| 事项 | 已确认内容 |
| --- | --- |
| 中文书名 | 《普通人的 AI 编程》 |
| 副标题 | 做出适合自己的工作工具 |
| 读者 | 没有编程背景、经常需要处理电脑工作的人；熟悉自己的业务，不默认会用终端或开发环境 |
| 核心论点 | 不必先成为程序员，也可以借助 AI，把自己熟悉的工作方法变成适合自己的工具 |
| 内容目标 | 让读者做出适合自己的工作工具，能够核对结果并再次使用 |
| 核心案例 | 固定汇报文件更新为主线，批量处理工作截图用于起步，整理报销票据用于迁移 |
| 案例分工 | 主案例承担案例篇幅的一半以上；三个案例穿插论述，不扩为三份独立软件教程 |
| 案例真实性 | 可用高还原度教学人物、数据和整理对话，须标注性质；实际效果和读者成功需另外验证 |
| 内容深度 | 正文解释必要判断、概念与操作；易变的安装、界面与排错细节放入配套资料 |
| 制作方式 | 由 AI 协助选择、接入成熟库或项目；成果可为脚本、skill 或小工具，实现形式按需要选择 |
| 范围边界 | 不以职业开发、创业商业化或企业系统建设为主线；不使用 Wombat 或李笑来的个人案例 |
| 写作形式 | 连贯论述、工作问题与必要实践结合，保留选择理由、失败与适用条件 |
| 语言与传播 | 中文先行，面向全球多语言，考虑各语言自然表达和 Google SEO，不编造搜索量或排名 |
| 仓库与许可 | `ai-coding-for-everyone`；原创书稿 CC BY-SA 4.0，原创代码 MIT，第三方内容按原许可 |
| 协作方式 | 直接使用仓库规则文件；中文表达、ASD-STE100 方法与审稿要求由 AGENTS.md 引用 |

五部分顺序以 [全书脉络](../book/zh-CN/README.md) 为准。各案例的具体完成标准以 [案例说明](../examples/README.md) 为准，许可范围以 [许可说明](../LICENSE.md) 为准。

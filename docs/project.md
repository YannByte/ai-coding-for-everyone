# 项目范围与进度

## 定位

帮助没有编程背景、经常使用电脑工作的人，用 AI 做出适合自己的工作工具。读者熟悉自己的业务，但不默认具备终端、开发环境或代码知识。

重点是个人可以使用、结果可以核对的工具。技术知识按需要解释；职业开发、商业化和企业系统建设不在本书主线中。

## 已确定

- 中文书名与副标题。
- 核心论点及五部分脉络。
- 固定汇报主案例、截图起步案例、票据迁移案例。
- 采用高还原度教学案例，区分教学设定与实测结果。
- 中文先行、多语言逐步推进。
- 书稿 CC BY-SA 4.0，代码 MIT。

## 接下来的工作

1. 收紧各案例第一版与最终成果的边界。
2. 制作原始材料、模板与对照结果，记录实际试做过程。
3. 以主案例推进过程细化逐章论点。
4. 完成一个样章，邀请符合读者定位的人试读、试做。
5. 根据反馈调整目录与材料，再展开正文。

尚未确定总字数、章节数、具体 AI 工具、英文正式书名或发布日期。案例设计不代表已经验证效果。

# 项目范围与进度

方向修正日期：2026 年 10 月 17 日。用户明确要求：帮助读者高效使用 AI 编程助手，有无编程经验都可以。此前将方向解释成「开发第一个 Agent 应用」有误，以下定位替代该解释。正式书名、案例和工具组合仍待确定。

## 已确认的方向

一本帮助有无编程经验的读者有效使用 AI 编程助手，做出、检查并维护自己需要的软件的书。

| 事项 | 当前决定 |
| --- | --- |
| 读者 | 有具体软件需求的人，有无编程经验都可以；基础概念随用随讲，有经验的读者可跳读基础解释 |
| 内容目标 | 帮助读者借助现成的 AI 编程助手理解代码、实现需求、修复问题、验证改动和完成交付，减少无效往返与返工 |
| 核心方法 | 从真实开发任务出发，解释如何组织任务、提供上下文、让助手执行任务、核对证据并积累可复用的工作方式 |
| 高效的含义 | 在结果正确、改动可维护的前提下，减少人工投入、等待与返工，合理使用模型额度和 Token；不能只以生成速度或 Token 数量判断效率 |
| 阅读方式 | 可以沿开发任务顺序阅读，也能根据具体困惑进入相应章节 |
| 写作重点 | 每章帮助读者作出具体决定，解释为什么、怎样做、做完检查什么；保留失败、取舍和适用条件 |
| Wombat 的关系 | 使用行为、上下文、配置、耗时与用量分析可提供研究线索；不把 Wombat 作为贯穿案例，不要求读者安装，不将规划能力写成已验证经验 |
| 案例与证据 | 使用独立、可公开的普通软件项目和开发任务；教学设定、来源自述、作者试做与读者试做分别标明 |
| 复用方式 | 复杂或需要持续打磨的通用能力，优先复用有维护、测试和许可依据的开源项目与库；让助手调查、配置、适配和验证，把新代码集中在已确认的需求缺口。复用已有边界处理经验，仍需验证当前用法，不保证开源必然可靠 |
| 语言与传播 | 中文先行，保留多语言方向；在线章节围绕明确问题组织，搜索需求不能替代全书教学顺序 |
| 许可与规则 | 原创书稿和教学素材 CC BY-SA 4.0，原创代码 MIT；中文写作与 ASD-STE100 方法继续用普通规则文件维护 |

正文称呼、Agent 概念与产品名的使用以 [术语表](terminology.md) 为准。

## 内容边界

本书研究读者如何使用现成 AI 编程助手工作，不以开发 Agent 应用、实现执行循环、建设评估平台或模型训练为学习目标。Agent 内部机制只解释到有助于使用者作出判断的程度。

正文覆盖任务表达、上下文、项目规则、执行指导、代码审查、测试、排错、恢复、复用和日常复盘。Skills、MCP、Hooks、并行任务等只在实际需要时讨论使用条件，不按功能列表逐项扩章。仓库写作规范仍是普通规则文件。

编程经验不作为门槛。本书不以面试题库、创业商业化或工具按钮说明为主线。产品操作差异与易变配置放入配套资料，具体能力按所用版本核对。每个选题都要说明它帮助读者完成哪项工作，避免转回 Agent 系统开发课程。

## 替代关系

本方向取代 [2026 年 10 月 11 日的项目定位](project-2026-10-11.md) 与 [原全书脉络](../book/zh-CN/outline-2026-10-11.md)。原书名《普通人的 AI 编程》及副标题退出当前定位；固定汇报、截图、票据三个案例和一页汇报样章保留为历史设计。

同日讨论过的「帮助开发者完成第一个 Agent 项目」及其 18 章工程大纲，已被本次用户纠正替代；不再沿用搭建 Agent、设计工具重试系统和建设评估框架等学习目标。原工作名《Agent 工程实战：调试、评估与改进》也不作为当前书名。

此前「只面向有编程基础的开发者」的限制取消。历史办公案例仍不自动恢复为当前案例。

仓库暂保留现有名称和地址。正式中英文书名与是否改名另行确定。

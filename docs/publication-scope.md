# 公开内容范围

## 当前公开

中英文项目介绍、中文全书脉络、项目范围、案例设计、参考来源索引、贡献说明和许可，以及整理后的写作规则、章节材料卡、证据状态与工作状态。公开记录标明未完成事项，不包含原始对话和私人文件。

## 完成后逐步公开

经过审阅的正文、原创教学文件、经过试做的配套代码、对照输出、必要的运行说明与排错记录，以及经过校对的翻译。

## 留在写作工作区

未采纳的选题和书名讨论、原始对话、未经整理的研究笔记、私人文件，以及许可未明确的外部下载附件。公开时采用必要的事实摘要和来源链接。

## 发布时检查

- 文件是原创，或具备适用的公开许可。
- 不含个人信息、凭据、本机路径或非公开工作资料。
- 教学设定、来源自述和实际验证结果有明确区分。
- 文档所说的文件、功能与验证确实存在。
- 翻译能对应到具体原文版本。

## 案例素材登记

案例目录中的表格、图片、PDF、演示文件、压缩包及其他非代码输入输出，须在 [素材清单](../examples/materials.json) 中逐文件登记。Markdown 说明、源代码、依赖锁文件及程序配置不作为练习素材登记；若 JSON、文本等文件实际充当输入输出，也必须登记。

清单是数组，每项包含：`path`（仓库内相对路径）、`origin`（`original` 或 `third-party`）、`license`（适用许可）、`description`（用途与教学性质）。外部材料还须有 `source`（公开来源 URL）。

登记不等于许可获批。原创素材按本项目许可；外部材料需人工核实允许再分发的范围并保留必要声明。只有链接而未收录文件的参考资料放在 [来源索引](sources.md)。

检查器要求常见附件格式登记，并核对清单的字段、文件存在性与路径。它不检查二进制内容中的个人信息，也无法自动判断所有文件的用途；这些仍需人工审阅。

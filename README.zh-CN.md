# 普通人的 AI 编程

**做出适合自己的工作工具**

[English](README.md) · [全书脉络](book/zh-CN/README.md) · [案例设计](examples/README.md)

这本书面向没有编程背景、但经常需要处理电脑工作的人，帮助你借助 AI，把熟悉的工作方法变成适合自己的工具。

你可能每个月都在更新同一份汇报，经常逐张调整截图，或者把散落的文件整理成别人能直接使用的材料。你知道哪些步骤麻烦、哪些地方容易出错，也知道什么结果才算完成。这些经验，是制作工具的起点。

## 这本书会讲什么

从一件具体工作出发，说清需要，拿出材料，借助 AI 制作第一版，检查结果，再处理下一次使用时出现的变化。必要的编程知识会在遇到问题时解释。

现成软件、成熟开源库和已有项目都可以利用。让 AI 协助查找、比较和接入，读者无须先知道库名。成果可以是脚本、skill 或小软件，形式由用途决定。

| 案例 | 作用 | 希望完成的工作 |
| --- | --- | --- |
| 固定汇报文件更新 | 贯穿主线 | 将 Excel 最新数据更新到固定 PPT，保留可用的汇报版式 |
| 批量处理工作截图 | 起步实践 | 转换、压缩图片，保留使用场景需要的清晰度 |
| 整理报销票据 | 方法迁移 | 将材料整理为适合本人需要的 PDF 与清单 |

三个案例穿插在全书论述中。讨论会涉及为什么这样做、怎样判断结果，以及不合用时怎样继续。
